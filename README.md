# Qt/QML калькулятор

## Сборка

Нужны Qt6 (Quick, Qml, Core) и CMake ≥ 3.16.

По идее достаточно просто запустить сборку приложения. Внешняя библиотека тоже собирётся, но это проверялось только на Linux
По этому достаточно:
```bash
mkdir build && cd build
cmake .. && cmake --build .
```

Если программа не видит внешнюю библиотеку:
```bash
# 1. Внешняя библиотека (аналог DLL/SO с DoIt)
cd external_lib && mkdir build && cd build
cmake .. && cmake --build .
cd ../..

# 2. Положить внешнюю библиотеку рядом с исполняемым файлом,
#    чтобы приложение нашло её при старте
cp ../external_lib/build/libdoit.so .
```
